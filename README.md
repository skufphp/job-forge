# JobForge

**JobForge** — учебный backend-проект (Job Listing Application), созданный на **vanilla PHP** без использования готовых фреймворков.

Проект разрабатывается с целью **глубокого понимания внутренней архитектуры веб-приложений**: маршрутизации, контроллеров, middleware, работы с сессиями и базой данных.

> 🎯 Основной фокус проекта — **создание собственного мини-фреймворка**, а не UI или frontend-логики.

---

## 🚀 Цели проекта

* Понять, **как работают фреймворки изнутри** (на примере Laravel-подобной архитектуры)
* Реализовать кастомный **Router** с поддержкой:

    * HTTP-методов (`GET`, `POST`, `PUT`, `DELETE`)
    * параметров маршрутов (например, `:id`)
    * middleware (`auth`, `guest`)
* Построить понятную структуру проекта:

    * разделение **Framework / App**
    * контроллеры, представления, partials
* Реализовать полноценный **CRUD** для вакансий
* Добавить аутентификацию, авторизацию и flash-сообщения
* Закрепить работу с **PDO**, сессиями и валидацией данных

---

## 🧱 Технологии

* **PHP** (vanilla)
* **MySQL** (через PDO)
* **Composer** (autoload, PSR-4)
* **Tailwind CSS** (готовая тема, без фокуса на UI)

---

## 📦 Функциональность (на текущий момент / в процессе)

* Просмотр списка вакансий
* Просмотр одной вакансии
* Регистрация и авторизация пользователей
* Размещение вакансий (только для авторизованных пользователей)
* Редактирование и удаление вакансий (только владельцем)
* Flash-сообщения
* Middleware для защиты маршрутов

## 🗂 Структура проекта (в процессе формирования)

```text
jobforge/
├── app/            # Контроллеры и представления
├── framework/      # Ядро приложения (Router, Session, Database и т.д.)
├── public/         # Точка входа (index.php)
├── routes/         # Описание маршрутов
├── views/          # Представления и partials
├── vendor/         # Composer dependencies
└── composer.json
```

> Структура будет постепенно эволюционировать по мере развития проекта.

## ⚙️ Установка и запуск (базово)

1. Клонировать репозиторий
2. Установить зависимости:

   ```bash
   composer install
   ```
3. Настроить document root на папку `public`
4. Создать базу данных и обновить конфигурацию подключения
5. Запустить проект через локальный сервер
